# ☕ SWYNEX Interactive Cafe Sales Dashboard

## 📊 Project Overview

This project was completed as part of my Data Analysis Internship at SWYNEX Technologies.

The objective of this project was to build an interactive and professional Cafe Sales Dashboard using Microsoft Power BI to analyze sales performance, product performance, transaction trends, payment methods, and location-wise performance.

## 🎯 Objectives

- Analyze overall cafe sales performance
- Track key performance indicators (KPIs)
- Analyze monthly revenue trends
- Identify top-performing products
- Analyze quantity sold by product
- Understand payment method distribution
- Compare revenue across locations
- Build an interactive dashboard using Power BI

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## 📌 Key KPIs

- Total Revenue
- Total Transactions
- Total Quantity Sold
- Average Transaction Value
- Average Unit Price

## 📈 Dashboard Features

The dashboard includes:

- Monthly Revenue Trend
- Revenue by Product
- Quantity Sold by Product
- Transactions by Payment Method
- Revenue by Location
- Interactive slicers for Date, Item, Payment Method and Location

## 🧹 Data Preparation

The dataset was prepared before visualization.

Key data preparation steps included:

- Handling missing values
- Replacing missing categorical values with "Unknown"
- Validating data types
- Preparing date fields
- Creating month and month-sort fields
- Creating DAX measures for KPIs

## 💡 Key Insights

- Salad generated the highest revenue among the products.
- Juice recorded the highest quantity sold.
- Monthly revenue varied throughout the year.
- Payment method and location data contained missing values, which were handled as "Unknown" where appropriate.
